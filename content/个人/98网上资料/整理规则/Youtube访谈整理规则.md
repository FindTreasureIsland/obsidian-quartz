# Youtube访谈整理规则

## 一、输入材料特点

- 素材来源：YouTube自动字幕（ASR）生成的中文转录稿
- 常见问题：乱码、重复片段、中英文混杂、识别错误、同段对话多次叠加

## 二、识别与还原

| 错误类型 | 示例 | 修正方法 |
|----------|------|----------|
| 人名乱码 | 记超→季逸超；WtoV→Word2vec；Membrowser→猛浏览器 | 结合上下文与技术名词常识还原 |
| 英文误识别为中文 | "Vibe ARR"→"ARR"；"TMD"→"他妈的" | 识别产品/技术术语的英文原词 |
| 重复叠加 | 同一段话被重复3-5次 | 保留一次，删除其余 |
| 乱码片段 | 大量无意义字符，字词之间有空格 | 直接删除或还原为连续中文 |
| ASR识别错误 | "时个时候"→"那个时候"；"那那个"→"那个" | 口语化还原 |

## 三、整理步骤

1. **识别说话人**：通过开头自我介绍确认采访者与受访者
2. **合并重复片段**：删除同一内容的多次重复
3. **按主题分段**：根据内容自然转场划分章节
4. **还原ASR错误**：
   - 修复空格乱码（如"让 我 觉 得"→"让我觉得"）
   - 还原人名/公司名（如"DPC"→"DeepSeek"，"Mus"→"Manus"）
   - 还原技术术语（如"attation"→"Attention"）
5. **清理语气词**：仅删除无意义的语气助词（嗯、啊、这个这个）
6. **合并重复表达**：同一观点的多次表达可以合并保留一次，但不做总结或归纳
7. **删除非内容元素**：删除NotebookLM等工具生成的提示语、视频时间戳等信息
8. **删除原文**：整理完成后，删除原始ASR转录文件，仅保留整理后的文档

## 四、格式规范

### 4.1 对话标注
- 格式：`**姓名**：`（直接使用姓名，不加"采访者"或"受访者"前缀）
- 示例：`**张小珺**：`、`**何俊贤**：`
- 开头信息块使用：`**姓名**（角色/职位）`

### 4.2 文档结构
- **Frontmatter**：标准YAML格式（必填）
- **开场信息块**：采访者、受访者、日期、主题
- **摘要**：访谈核心要点概述（200-500字）
- **视频嵌入**：在摘要之后插入YouTube视频链接
  ```markdown
  ![](https://www.youtube.com/watch?v=视频ID)
  ```
- **分隔线**：视频链接后加 `---`
- **章节结构**：使用 `##` 二级标题，按内容自然分段
- **⚠️ 章节内容原则**：对话内容必须逐句原文保留，不得做总结或归纳
- **术语表**：技术术语汇总表（可选）
- **相关链接**：视频链接、来源链接（可选）

### 4.3 文件命名
- 格式：`YYYY-MM-DD_采访者采访受访者_主题.md`
- 示例：`2026-04-18_张小珺采访何俊贤_DeepSeek技术解读.md`

### 4.4 Frontmatter字段
```yaml
---
title: 文档标题
source: 视频/来源URL
author:
  - 采访者（角色）
  - 受访者（角色/职位）
published: 发布日期
created: 整理日期
description: 访谈内容简述
tags: [标签1, 标签2]
---
```

## 五、章节划分建议

| 章节类型 | 说明 |
|----------|------|
| 开场与背景 | 自我介绍、研究方向、工作预告 |
| 起源与观察 | 受访者对主题公司的早期关注和观察 |
| 核心内容 | 按主题划分多个技术/观点章节 |
| 总结与展望 | 受访者的总结性观点、未来展望 |
| 结语 | 节目收尾 |

### 子章节格式
- 使用 `###` 三级标题
- 按主题内容自然分段
- 技术解读可使用编号（如 6.1、6.2）

## 六、避坑提示

- **✅ 保留原文**：对话内容必须原文呈现，不得归纳、概括、改写
- **✅ 可以合并**：同一观点的多次表达可以合并保留一次
- **❌ 不要做总结**：禁止将对话改写为第三人称叙述，禁止提炼"核心观点"
- **敏感内容处理**：如涉及人身攻击或过度隐私，酌情保留或标注
- **技术准确性**：涉及技术术语时，确保名词还原正确
- **删除AI生成内容**：NotebookLM等工具的"教我..."、"来源指南"等提示语需删除

## 七、常见问题处理

### 7.1 ASR空格乱码
```
原文：讓 我 覺 得 非 常 的 就 是 尊 重 他 們 的 工 作
修正：让我觉得非常的就是尊重他们的工作
```

### 7.2 人名/公司名确认
- 采访者：需在开头自我介绍中确认
- 受访者：需在开头自我介绍中确认
- 公司名：可通过上下文或常识判断（如"dpsic"→"DeepSeek"）

### 7.3 删除的元素
- NotebookLM的"来源指南"
- NotebookLM的提问提示（如"教我一切关于..."）
- 视频时间戳和进度条信息
- Google账号信息等无关内容
