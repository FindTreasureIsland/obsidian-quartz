# V3 到 V4，DeepSeek 484 天的人、财，事、物

**来源**：https://www.woshipm.com/ai/6384771.html

**作者**：赤潮AKASHIO

**发布时间**：2026-04-27

**核心主题**：DeepSeek-V4 发布不仅是技术迭代，更是中国 AI 产业生态的重要转折点

---

## 核心观点

DeepSeek 正在成为整个中国算力产业链的"凝结核"，串联起所有的线索。

**484天前**（2024-12-26）：DeepSeek-V3 发布，557万美元训练成本，让硅谷震动
**484天后**（2026-04-24）：DeepSeek-V4 发布，腾讯和阿里争相投资，估值200亿美元以上

故事从"低成本神话"变成了"不得不学习现实重力的技术理想主义者"。

---

## 一、人：离开的那部分，叫方向

### 核心人才流失

2026年4月16日，郭达雅加盟字节跳动 Seed 团队——R1 推理能力的重要贡献者，尤其与 GRPO 强化学习方法相关。

此前多名 DeepSeek 核心成员离职：
- 罗福莉 → 小米 MiMo（端侧）
- 王炳宣 → 腾讯（补 AI 底座）
- 阮翀 → 元戎启行（自动驾驶多模态）
- 魏浩然 → 去向不明
- 郭达雅 → 字节 Seed（Agent）

### 深层原因

**不只是被钱挖走，走的还有路线。**

DeepSeek 最强的地方在基座模型，在推理模型，在把训练和推理成本压到极致。组织文化偏向：把模型本身做得更强、更便宜、更开源。

但2025年之后，行业的兴奋点开始转移——大家要的是 Agent：会写代码、会调用工具、会跨应用执行任务、会记住上下文、会在产品里形成闭环。

DeepSeek 的优势反而变成约束：研究员如果想研究 Agent，在 DeepSeek 内部面对的是一个更偏底座的组织；去字节，面对的是豆包1.57亿月活的真实用户场。

### 身份转换压力

梁文锋面对的现实问题：
- 如果要留住人 → 要让 DeepSeek 股权有价格
- 要股权有价格 → 要进入资本市场的语言系统
- 进入资本市场 → 必须回答：你怎么赚钱？怎么增长？怎么防止别人用你的开源模型赚走所有的钱？

## 二、财：557万美元的神话，总要补账

### 低成本神话的代价

**第一层束缚：公众预期**
- V3 用 557 万美元让全世界震动
- 下一次发模型时，人们不会只问强不强，还会问够不够便宜
- 像厨师用10块钱做出米其林水准的饭——第一顿是神话，第二顿开始所有客人都会问还能不能10块钱继续做

**第二层束缚：真实成本**
- 557 万美元 = 一次训练的 GPU 小时
- 不包含：前期架构探索、失败实验、数据建设、工程团队、硬件储备、推理服务、用户爆发后的扩容成本
- SemiAnalysis 估算 DeepSeek 硬件总支出超过 **13亿美元**

### 融资压力

- Reuters：DeepSeek 洽谈至少3亿美元融资，估值超100亿美元
- 腾讯和阿里参与谈判，估值推到200亿美元以上
- 中文创投圈版本：融前估值3000亿人民币，增资500亿人民币，50亿起投门槛

**50亿门槛筛掉的是想财务投资的人，DeepSeek 要的是资源型股东**：云算力、政企客户、合规背书、芯片供应链、模型分发渠道。

## 三、事：开源模型变成了别人的武器

### R1 爆红的后果链

R1 发布 → 全球股市震动 → 美国 IP 和安全叙事反扑 → 国内大厂集体 DeepSeek 化 → 大厂接入证明基础设施价值 → 基础设施价值逼它回答商业化问题

### 腾讯的操作

2025年2月13日，腾讯元宝接入 DeepSeek-R1 满血版。

这不是 DeepSeek 被腾讯拯救——这是腾讯用 DeepSeek 拯救自己的 AI 产品线。

元宝 DeepSeek 模式单日使用量较年初增长超过 **100倍**。

### 开源的悖论

> 开源模型最锋利的地方，是它能让所有人都使用你。
> 开源模型最残酷的地方，也是它能让所有人都使用你。

- 腾讯把 DeepSeek 接进元宝
- 阿里把 DeepSeek 放进云服务
- 创业公司拿 DeepSeek 做代码助手
- 政企客户让云厂商私有化部署

每一次使用都在扩大 DeepSeek 的影响力，但也可能绕过 DeepSeek 的收入表。

### 和 Android 的类比

Android 让全世界手机厂商拥有了对抗 iPhone 的操作系统，但真正长期吃到最大红利的不是每一个 Android 手机厂商，而是掌握应用商店、广告系统、账号体系和云服务的 **Google**。

DeepSeek 提供了基础层，但基础层上方的城市，正在被别人迅速施工。

## 四、物：从 H800 到昇腾，一场换芯手术

### 芯片封锁的背景

美国芯片封锁已经从"不给最强芯片"发展到"给你算总账"：
- 2025年1月：拜登政府发布 AI Diffusion Rule
- H20 的拉扯：一个窗口，限制、恢复、再限制
- 对于前沿模型公司，这种不确定性比贵更危险

### 转向华为昇腾

2026年4月，DeepSeek-V4 将运行在华为芯片上。

这不是爱国叙事，是面对供应链风险时的理性选择。

**"Day zero"适配**：华为 Ascend 950PR 与 950DT 对 DeepSeek-V4 实现发布当天适配

### 从 CUDA 到 CANN 的难度

- 需要算子重写、编译器适配、推理框架优化
- 通信互联调度、显存管理、长上下文性能验证
- 万亿参数、百万 token 上下文，任何环节效率不够都会把"国产适配"变成 PPT 适配

### Jensen Huang 的"horrible outcome"

TNW 解读：DeepSeek 花了数月重写核心代码适配华为 CANN 框架，离开 Nvidia 花了二十年建成的 CUDA 生态。CUDA 的统治本身就是美国在芯片之外的第二层控制。

**Nvidia 真正害怕的**：不是一个强模型在非 CUDA 生态里稳定运行。强模型可以被解释为偶然、蒸馏、补贴、不可持续。但一个强模型在非 CUDA 生态里稳定运行，说明 CUDA 的护城河可以被绕过。

## 总结

DeepSeek 的484天，是一个技术理想主义者不得不重新学习现实世界的重力的过程。

**人**：核心人才被大厂用真金白银和用户场分流
**财**：557万神话掩盖了13亿硬件支出的真相
**事**：开源的胜利不自动属于开源公司
**物**：从 H800 到昇腾，是一场没有退路的换芯手术

**核心问题**：DeepSeek 能否从"子弹"变成"枪"？子弹射穿硅谷算力神话之后，枪管、弹匣、后勤、士兵、工厂、补给线，都开始要钱。
