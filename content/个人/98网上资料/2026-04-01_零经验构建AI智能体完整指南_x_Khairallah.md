## 核心内容

一个面向零经验者的周末AI Agent构建完整指南。

## Agent vs Chatbot：真正区别

**Chatbot（聊天机器人）**：你问问题，它回答，结束。

**Agent（智能体）**：你给目标 → 它拆解步骤 → 用工具完成 → 持续迭代直到目标达成。

关键区别就一个字：**自主性**。

### 真实案例对比

**Chatbot 回答**：
> "阿姆斯特丹现在12度，多云。"

**Agent 回答**：
> "明天有会议，建议带伞。2pm-4pm有70%概率下大雨，也可以考虑改到室内。"

Agent 没有只回答问题——它理解了目标（帮会议做准备），获取了所需信息（天气预报、时间），使用了工具（天气API），给出了可执行的建议。

## 周末构建计划

### 周六上午：工具准备（2小时）

**Step 1：获取 Claude API 访问**
- 访问 console.anthropic.com
- 创建账户、添加计费、获取 API key
- 费用：个人项目非常便宜，周末测试只需几美元

**Step 2：安装 Python**
- 从 python.org 下载最新版
- Mac：Terminal 应用；Windows：Command Prompt 或 PowerShell

**Step 3：项目初始化**

```bash
mkdir my-first-agent
cd my-first-agent
python -m venv venv
source venv/bin/activate  # Mac/Linux
# venv\Scripts\activate  # Windows
pip install anthropic
```

### Agent Loop 工作原理

每个 Agent 都遵循同样的循环：

```
发送目标 + 工具描述 → Claude 判断是否需要工具
    ↓ 是
执行工具 → 把结果发回 Claude
    ↓
Claude 判断是否需要更多工具或目标已达成
    ↓
重复直到完成
```

这个循环就是 Agent 的全部概念，其他都是细节。

### 周六下午：构建 Agent 大脑（3小时）

**Step 4：构建简单 Agent**

创建 `agent.py` 文件，让 Claude 生成完整的 Agent 脚本。

设置 API key：
```bash
export ANTHROPIC_API_KEY=your-key-here
```

运行测试：
```bash
python agent.py
```

测试目标示例："847的15%是多少？这是正常的小费吗？"

你会看到 Agent：
1. 思考问题
2. 决定使用计算器
3. 获取结果
4. 判断是否是正常小费
5. 给出最终答案

### 周六晚上：添加真实工具（2小时）

**Step 5：添加真实搜索工具**

用 Tavily 搜索 API（慷慨的免费额度）替换模拟搜索函数。

关键升级：Agent 不再查询模拟数据，而是真正搜索网络、处理结果、融入推理。

**Step 6：添加文件读取工具**

添加让 Agent 读取本地文件的工具。现在 Agent 可以回答关于本地文档的问题了。

两个工具（搜索 + 文件读取）已经让 Agent 能做真实任务了。

### 周日上午：对话能力（2小时）

**Step 7：添加对话记忆**

目前 Agent 一次只处理一个目标。添加对话历史后，Agent 记住所有讨论内容，能在之前的答案上继续。

这是"一次性工具"和"助手"的区别。

**Step 8：添加错误处理**

真实工具会失败：API超时、文件不存在、数据格式错误。

为每个工具添加适当的错误处理——结构化错误信息告诉 Agent 哪里出了问题、下一步怎么做。

好的错误处理是 Demo 和日常使用工具的分界线。

### 周日下午：完善和测试（2小时）

**Step 9：用真实任务测试**

给 Agent 10个不同的任务——简单的和复杂的：
- "本周天气预报是什么？"
- "读我的会议记录，提取行动项"
- "研究最新新闻并写一段总结"
- "计算10000美元5%年利率10年的复利"
- "找阿姆斯特丹评分好的三家餐厅并比较"

**Step 10：添加自定义工具**

这是毕业练习。想一个你日常工作或生活中重复做的任务，构建对应的工具。现在你有了一个根据你特定需求定制的个人 AI Agent。

## 你构建了什么

一个 Python 脚本，能够：
- 接收自然语言目标
- 推理如何实现
- 使用多个工具收集信息
- 进行计算
- 优雅处理错误
- 维护对话历史
- 可以扩展任何新工具

**这是一个真正的 AI Agent。** 不是聊天 API 的封装，是一个能推理和行动的真正自主系统。

## 后续发展路线

**第2周**：根据实际需要添加3-5个工具（天气、日历、邮件、文件创建、数据分析）

**第3周**：部署到树莓派、便宜的云服务器或笔记本电脑上，连接到 Telegram 或 WhatsApp

**第2个月**：学习多 Agent 架构，构建多个专门 Agent 协同工作的系统

**第3个月**：开始为别人构建 Agent。这是 businesses 会付费的技能。

## 核心观点

你的第一个 Agent 会粗糙——会犯错、偶尔用错工具或给出奇怪的答案。

这完全没关系。每个开发者都是从粗糙开始的。

重点不是完美，重点是通过实际构建来理解 Agent 是如何工作的。这种理解比任何阅读或观看教程都有价值。
