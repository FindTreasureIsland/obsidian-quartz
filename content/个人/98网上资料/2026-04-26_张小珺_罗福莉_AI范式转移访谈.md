# 罗福莉×张小珺访谈：AI范式转移的关键判断

## 人物背景

罗福莉：阿里达摩院 → DeepSeek（V2核心作者）→ 小米大模型团队 MiMo 负责人
标签：第一次深度技术访谈、千万年薪

---

## 核心判断：AI范式已转移

**预训练主导的 Chat 时代 → 后训练主导的 Agent 时代**
- 标志性事件：OpenClaw 出现 + Claude Opus 4.6 发布

---

## OpenClaw 体验笔记

**三天认知被彻底刷新：**

| 天 | 感受 |
|---|---|
| 第1天 | 凌晨2点装上，兴奋到睡不着——「灵魂感」，产品设计的温度和情商 |
| 第2天 | 能完成以前做不了的事（日常生活+工作） |
| 第3天 | 把研究任务交给它，一两小时完成以为要很久的 User Agent 构建 |

**技术判断：** 精心编排的 Agent 框架可以大幅弥补模型本身的短板
- 中层模型 + 好框架 → 85% 任务接近 Claude Sonnet 水准
- 3B 端侧小模型 + 同一框架 → 超乎想象

## 小米团队：被 OpenClaw 彻底点燃

- 规定：所有人必须用 OpenClaw，对话次数 < 100 轮/天 就辞职
- 100人在飞书群疯狂探索，10分钟不看就 999+
- **结果：** 3-4周完成以前 30-40 周的研究量

## 大模型竞争格局判断

1. **Anthropic 路径正确**——已是行业共识
2. **国内预训练代差基本消除**——大家站在同一条起跑线
3. **1T 参数** 是接近 Claude Opus 4.6 水平的入场券
4. **核心赛点：** Agent 场景下强化学习的 scaling

## 算力分配：范式转移的量化证明

| 时代 | 研究 : 预训练 : 后训练 |
|---|---|
| Chat 时代 | 3 : 5 : 1 |
| Agent 时代 | 3 : 1 : 1 |

预训练和后训练算力投入已持平，顶尖团队基本都是 1:1

---

## MiMo 技术路线：MTP 优于 MLA

**MLA**（Chat时代优秀结构）：计算和访存比例优化到极致临界点 → 没有灵活调整空间

**Hybrid Attention + MTP**（MiMo选择）：天然适合 Agent 场景
- 长上下文成本低
- 推理速度快
- 架构有弹性

> "这个选择当时有一定偶然性，但回头看恰好完美适配了 Agent 时代的需求"

---

## 组织管理：极度扁平实验

- 100人团队，**无职级、无小组、无 deadline**
- 训练 1T 模型的核心团队只有几个人
- 哲学：平权有利于创新，任何层级都是规范和约束
- 招人标准：**好奇心 + 热爱** > 经验
- 倾向招大二大三本科生——"想象力没有被禁锢"
- 团队成长方式：「互相蒸馏」

## AGI 时间表（激进判断）

- 目前已走到 **20%**
- 今年年底 → **60%-70%**
- 两年内应该能实现

**颠覆顺序：** 工作模式 → 生活模式（等机器人技术跟上）

## 最震撼的判断

> "训模型这种工作足够有创造力，不会被 Skill 化和 Workflow 化。但现在发现，AI 竟然也能做到。那它能不能自己训出更强的模型？自己左脚踩右脚就提升了？"

**这是 1-2 年内会发生的事情。**
