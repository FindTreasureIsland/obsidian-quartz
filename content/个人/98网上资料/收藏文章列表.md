## 一、为什么Skills比Prompts更重要

很多人问我：如何提升Claude Code的工作效率？

我的答案是：别再纠结写更好的prompt了，真正重要的是构建更好的**Skills**。

在Anthropic内部，我们有数百个Skills在生产环境中运行。这些不是简单的markdown文件，而是完整的文件夹结构，包含：

- **Scripts**：可执行脚本
- **Assets**：静态资源
- **Data**：数据文件
- **Hooks**：钩子函数

这是我从实际项目中总结的核心经验。

---

## 二、Skills的核心结构

一个高效的Skill应该包含以下文件：

```
my-skill/
├── SKILL.md          # 核心定义文件
├── scripts/          # 可执行脚本
├── references/       # 参考文档
└── data/            # 数据文件
```

### SKILL.md的关键字段

```yaml
---
name: skill-name
description: |  # 这是模型触发条件，不只是元数据
  当用户询问[X]时使用此技能
user-invocable: true
---
```

**关键点**：description字段是模型触发条件，这是最被低估的杠杆。

---

## 三、Description字段的妙用

大多数人会忽略description，但它才是真正让Skill生效的关键。

❌ 错误示例：
```yaml
description: "这个技能用于代码审查"
```

✅ 正确示例：
```yaml
description: |
  当用户要求审查代码、查找bug、优化性能时自动触发
  适用于Python、JavaScript、Go等主流语言
```

触发条件越精准，Skill调用越准确。

## 五、实战：构建一个代码审查Skill

### Step 1: 定义触发条件

```yaml
---
name: code-reviewer
description: |
  触发条件：
  - 用户提到"审查代码"
  - 用户提到"检查bug"
  - 用户提到"代码问题"
  - 文件后缀为.py/.js/.go/.java
---
```

### Step 2: 编写核心逻辑

在scripts/目录下创建审查脚本：

```python
# scripts/reviewer.py
def analyze_code(file_path):
    # 1. 静态分析
    issues = run_static_analysis(file_path)
    # 2. 模式检查
    patterns = check_common_patterns(file_path)
    # 3. 性能评估
    perf = assess_performance(file_path)
    return format_report(issues, patterns, perf)
```

### Step 3: 定义输出格式

```markdown
## 审查结果

### 🔴 严重问题
- [问题描述]
- [修复建议]

### 🟡 建议优化
- [优化点]
- [参考方案]

### 📊 质量评分
- 可读性: 8/10
- 性能: 7/10
- 安全: 9/10
```

## 六、我的最佳实践

### 1. 保持Skill职责单一

一个Skill只做一件事，比做一个大而全的Skill效果好10倍。

### 2. 善用Hooks

```yaml
hooks:
  pre-process: scripts/validate_input.py
  post-process: scripts/format_output.py
```

### 3. 版本管理

Skills应该像代码一样版本化管理，方便回溯和协作。

### 4. 共享复用

把通用的Skill分享到ClawHub，让团队成员都能受益。

---

## 七、常见错误避坑

| 错误 | 后果 | 解决方案 |
|------|------|----------|
| description太宽泛 | 频繁误触发 | 精确描述触发条件 |
| 一个Skill做太多事 | 难以维护 | 拆分多个Skill |
| 忽略错误处理 | Skill崩溃 | 添加try-except |
| 没有测试 | 上线就出错 | 先在本地测试 |

---

## 八、总结

Skills是AI Agent的"应用"，掌握它们才是真正的生产力的解锁之道。

不在于你写多好的prompt，而在于你构建多好的Skill体系。
