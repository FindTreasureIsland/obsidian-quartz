## 核心观点

- **"一个好 Skill 的效果，能等同甚至超越一个完整的 AI 产品。"**
- **"Skills 让 AI 从'通用助手'变成'领域专家'：装上 web-design-guidelines 就变成设计顾问，装上 seo-audit 就变成 SEO 专家。"**
- **"不用焦虑，也不用全装。看看自己平时的工作流程，哪些环节是重复的、费时间的，找对应的 Skill 装几个就行。"**
- **"生态还在快速发展，几乎每周都有新的好东西出来。我也会继续测试，有新发现再和大家分享。"**

## 安装建议

### 建议先装基础能力类（让AI真正跑起来）

1. **find-skills** (251.5K) - 帮你找到其他Skill
2. **skill-creator** (37.4K) - 创建自己的Skill
3. **mcp-builder** (9.9K) - 构建MCP服务器

### 按工作场景选择

| 场景          | 推荐 Skill                                                        |
| :------------ | :---------------------------------------------------------------- |
| 前端开发      | vercel-react-best-practices, next-best-practices, frontend-design |
| 视频/动画制作 | remotion-best-practices                                           |
| 移动端开发    | vercel-react-native-skills                                        |
| 自动化测试    | webapp-testing, agent-browser                                     |
| 内容创作      | copywriting, social-content, brainstorming                        |
| 营销推广      | seo-audit, marketing-ideas, page-cro                              |
| 文档处理      | pdf, pptx, docx, xlsx                                             |
| 设计类        | web-design-guidelines, canvas-design, baoyu-cover-image           |
