# 重点论文深度分析

## 论文1：Agentic Harness Engineering (AHE)

**论文信息**：
- 标题：Agentic Harness Engineering: Observability-Driven Automatic Evolution of Coding-Agent Harnesses
- 作者：Lin et al. (Fudan University, Shanghai AI Lab)
- arXiv：2604.25850
- 日期：2026/04/28

### 解决的问题

大多数 coding-agent 的 harness 仍然是手动调参，或靠脆弱的试错自我进化（trial-and-error self-evolution）。

**核心痛点**：
- 操作空间异构（不同组件）
- 大量轨迹数据埋没了可行动的信号
- 改动效果难以归因

### 核心方案：三层可观测性架构

| 层级 | 机制 |
|------|------|
| **组件可观测性** | 每个可编辑组件是版本化文件，可回滚 |
| **经验可观测性** | 从数百万轨迹 token 压缩成可消费的层级证据 |
| **决策可观测性** | 每次改动都有自我声明的预测，后续验证 |

### 核心创新

**把每次改动变成可证伪的契约（falsifiable contract）**

```
每次改动 = 声明预测 → 下轮验证 → 接受或回滚
```

### 实验结果

| 指标 | 结果 |
|------|------|
| Terminal-Bench 2 Pass@1 | 69.7% → 77.0%（10次迭代） |
| vs 人类设计的 Codex-CLI | 71.9%（AHE 胜出） |
| vs ACE/TF-GRPO 自进化基线 | 两者皆被超越 |
| Token 节省 | 12%（SWE-bench-verified） |
| 跨模型迁移 | +5.1 到 +10.1 pp（三个不同模型家族） |

### 关键洞察

**ablation 分析发现**：增益主要来自 tools、middleware、long-term memory，而非 system prompt。

→ **Harness 的结构化改进可以迁移，但 prose-level 策略不能**

### 意义

Harness work 是大多数 agent 系统最大的隐性成本。AHE 是第一个让 harness 自我改进但不会漂移到噪声的方案。

## 论文3：Agentic World Modeling

**论文信息**：
- 标题：Agentic World Modeling: Foundations, Capabilities, Laws, and Beyond
- 作者：Chu et al. (40位作者，来自多个顶尖机构)
- arXiv：2604.22748
- 日期：2026/04/24

### 解决的问题

当 AI 系统从生成文本转向通过持续交互完成目标时，建模环境动态成为核心瓶颈。但"世界模型"这个词在不同社区有不同的含义。

### 核心框架："Levels × Laws" 分类法

**三维能力层（Level）**：

| 层级 | 描述 | 特点 |
|------|------|------|
| **L1 Predictor** | 一步转移算子 | 学习局部转移操作 |
| **L2 Simulator** | 多步动作条件展开 | 遵循领域定律 |
| **L3 Evolver** | 自主修订模型 | 当预测失败于新证据时自我修正 |

**四类法律 Regime**：

| Regime | 描述 |
|--------|------|
| **Physical** | 物理定律 |
| **Digital** | 数字定律 |
| **Social** | 社会定律 |
| **Scientific** | 科学定律 |

→ 不同 regime 决定了世界模型必须满足的约束，以及最可能失败的场景

### 综合范围

- 400+ 论文综合
- 100+ 代表系统
- 覆盖：model-based RL、video generation、web/GUI agents、multi-agent simulation、scientific discovery

### 失败模式目录

论文提取了跨 100+ 系统的反复失败模式：
- 奖励塑造不对齐
- 非平稳性下的漂移
- 跨 regime 的脆弱迁移

### 评估原则

**按层级提出评估标准**，而非单一基准。

因为 L1 预测准确性和 L3 自我修订质量不在同一轴线上。

### 意义

这是第一个给 builders 提供跨社区共享词汇的论文。让之前孤立工作的各个社区有了统一的框架。

## 论文6：From Skill Text to Skill Structure (SSL)

**论文信息**：
- 标题：From Skill Text to Skill Structure: The Scheduling-Structural-Logical Representation for Agent Skills
- 作者：Liang et al.
- arXiv：2604.24026
- 日期：2026/04/27

### 解决的问题

当前 agent 系统中的 skill 仍然是文本密集型工件（SKILL.md 文件）。调用接口、执行流程、工具副作用都纠缠在一个 blob 的自然语言中。

这导致：
- 技能发现（discovery）困难
- 风险评估（risk assessment）脆弱

### 核心方案：SSL 三层结构

基于 Schank 和 Abelson 的经典工作（MOPs, Script Theory, Conceptual Dependency）：

| 层级 | 描述 |
|------|------|
| **Scheduling Layer** | 捕获调用信号和触发条件 |
| **Structural Layer** | 编码执行场景和排序 |
| **Logical Layer** | 指定原子动作 + 资源注解 + 副作用注解 |

### 关键创新

**解耦**：把 invocation interface、execution flow、side effects 从单一文本中分离。

**可发现性**：基于 LLM 的 normalizer 把现有 SKILL.md 文件转换为 SSL 结构，无需手动重写。

### 实验结果

| 任务 | 基线 | SSL | 提升 |
|------|------|-----|------|
| Skill Discovery MRR | 0.573 | 0.707 | +23% |
| Risk Assessment F1 | 0.744 | 0.787 | +5.8% |

### 关键洞察

结构化表示让检索显著更准确，即使没有任何模型微调。

**原因**：结构暴露了技能实际做什么，而非只是它们如何描述自己。

### 发布资源

- 6,184 个技能的语料库
- 403 个任务查询
- 500 个风险标注技能

### 意义

当技能注册表超过百万条目时，结构化表示是保持可发现性和可审查性的唯一途径。

## 三篇论文的关联性

```
Agentic Harness Engineering (AHE)
    ↓ 自我改进的工程系统
Agentic World Modeling
    ↓ 环境建模的分类框架
From Skill Text to Skill Structure (SSL)
    ↓ 可发现的技能库

三者共同指向：
构建可靠、可改进、可发现的 Agent 系统
```

## 对海极的启示

### AHE 的启示
Harness 的进化应该是可验证的工程过程，而非试错。海极在构建 AI 操作系统时，需要建立类似的机制：每次服务沉淀的共性能力是否可以被验证和回滚？

### World Modeling 的启示
三层能力（L1/L2/L3）对于理解 AI 能做什么、不能做什么很重要。海极的 AI OS 定位在哪个层级？

### SSL 的启示
技能库的"可发现性"和"风险评估"是未来 AI 系统的关键。技能如何被组织、如何被检索、如何被信任。
