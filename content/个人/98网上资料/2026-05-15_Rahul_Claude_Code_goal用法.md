#Claude_Code #AI编程 #工作流

**Rahul** @sairahul1 · 2026年5月15日

旧方式用 Claude Code：
Prompt → 等 → 检查 → Prompt → 等 → 检查 → 重复20次
你成了循环本身，成了条件检查器，成了它持续运行的原因。

新方式：
```
/goal all tests pass and lint is clean
```
Claude 自己去工作。你做别的事。回来时看结果。

附完整指南：/goal、/loop、/schedule 和 Stop Hooks 的正确打开方式。

> Most developers use Claude Code like an assistant they have to babysit. Type a prompt. Wait. Review. Type again. Wait again. Every step needs you to push it forward. There's a completely different way...
