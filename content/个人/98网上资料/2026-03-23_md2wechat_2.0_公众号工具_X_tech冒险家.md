## 核心内容

md2wechat 是一个 Markdown 转微信公众号的工具，v2.0 正式面向 AI Agent 生态，成为完整创作工具链。

## 核心升级

1. **主题系统**：内置7套主题，新增 dan-koe 和 Newsletter 风
2. **封面图生成**：集成 ModelScope，一键生成封面配图
3. **命令友好**：错误提示对 Agent 更友好，新增 capabilities、themes、prompts、providers 命令
4. **官网重构**：md2wechat.com 面向 AI Agent 生态，API文档、快速开始、博客、集成指南

## 上架 ClawHub 踩坑

- ClawHub 不允许 Skill 在安装时下载第三方可执行程序（安全红线）
- 解决：CLI 独立安装，Skill 只负责知识和工作流
- **教训**：Skill 和运行时必须解耦，别在 Skill 里塞可执行文件的下载逻辑

## 使用流程（Claude Code）

```bash
# 第一步，安装 CLI
brew install geekjourneyx/tap/md2wechat

# 第二步，安装 Skill
npx skills add https://github.com/geekjourneyx/md2wechat-skill --skill md2wechat

# 第三步，初始化配置
md2wechat config init
```

配置内容：
- 微信公众号凭证：AppID 和 AppSecret
- 图片服务：ModelScope（免费额度），模型选阿里通义造相 Tongyi-MAI/Z-Image-Turbo

第四步，一句话创作：
```
/md2wechat 帮我写一篇 dan-koe 风格的短文，封面配图使用维多利亚风格，主题是：自律其实很容易。
```

整个过程三分钟左右，从创作到发布草稿箱。
