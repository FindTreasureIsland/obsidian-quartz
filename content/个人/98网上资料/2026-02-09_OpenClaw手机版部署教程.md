# OpenClaw (Clawdbot) 手机版部署教程

**作者**: 卡神 Karu (@edwordkaru)
**时间**: 2026-02-09 15:39
**来源**: [原始链接](https://x.com/edwordkaru/status/2020764405584294275)

---

相信最近大家都看到好多人说安装了 Clawdbot 改变了人生，有的说赚了好几倍对吧？是的，我就是看太多了所以没忍住也想部署起来。

其实根本不需要很牛的 PC / Mac Mini，你只需要有一部旧手机就能把 OpenClaw 部署起来。这样我们就能先尝试部署玩玩看，之后有需要才去投资个 Mac Mini 来当服务器。

我本身就不是程序员，花了十多小时去部署，中途又出错 AI 不会启动。重装了好多次最后才成功，所以我把我的经验总结了，希望能帮助到想尝鲜的朋友们可以顺利部署不踩坑！

---

## 部署前要准备的事

### 1. 手机准备
先把你的手机数据全部清除回去出厂状态（隔离一切与你有关的信息）

### 2. API KEY
准备好 API KEY，买5-10刀的tokens就够了（我是用 Claude code 的）
- 访问 https://platform.claude.com/ 注册一个账号
- 去点 API KEY 购买个 5 刀的 API TOKEN就好了，反正只是想尝鲜
- 把你的 API KEY 复制好（API KEY 不要给别人看到）

### 3. Telegram Bot
在 Telegram 里找到 @BotFather
- 点 START
- 输入 /newbot 创建 TG Bot
- 输入 /mybots 点你刚创建的 Bot，点 API TOKEN 复制下来（API KEY 不要给别人看到）

---

## 现在可以部署 OpenClaw 去你的手机了

跟着我的步骤千万不要略过任何一个step，不然就会翻车

### 1. 安装 Termux App
Google Play / App Store 都可以下载

### 2. 更新资料包
打开 APP 开始输入指令更新资料包：
```
pkg update && pkg upgrade -y
```

### 3. 安装核心依赖
OpenClaw 需要 Node.js，Python 和编译工具，因为要编译 llama.cpp 等本地库：
```
pkg install nodejs-lts python make build-essential git -y
```

### 4. 安装 OpenClaw
大概 15-25 分钟因手机而定，手机会发热，请保持电量充足：
```
npm install -g openclaw@latest
```

### 5. 验证安装
输入以下命令，如果出现版本号和帮助信息，说明核心安装成功：
```
openclaw --help
```

### 6. 初始化与绑定（最关键的一步）
注意先后顺序，启动比较慢耐心等等：
1. 先输入 `termux-chroot`
2. 再输入 `openclaw onboard`

> termux-chroot 就是为了骗AI让它以为自己在Linux系统里而不是在手机，每次开启 Bot 前都要先输入这个指令

### 7. 启动服务
这时你会看到 "openclaw gateway error" 别担心，这很正常。输入这个指令就能正常启动了（启动比较慢耐心等等）：
```
openclaw gateway --verbose
```

---

## 小贴士

为了防止 AI 掉线，请：
1. 下拉手机通知栏，点击 Termux 通知里的 "Acquire wakelock"
2. 在手机设置里给 Termux 开启"允许后台高耗电"或"不进行电池优化"
