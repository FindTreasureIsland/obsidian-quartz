## 手把手教程（3 分钟领取）

### 第一步：注册 NVIDIA 账号

1. 打开官网：https://build.nvidia.com
2. 点击右上角的「Login」
3. 选择「Create Account」，填写邮箱（推荐 QQ 邮箱/Outlook）和密码
4. 去邮箱查收验证邮件，点击链接完成激活

### 第二步：验证手机号

1. 登录后页面顶部会出现「Verify your account to unlock API access」
2. 点击「Verify」，输入手机号（+86 开头即可），接收验证码并填写提交
3. 验证完成，解锁完整 API 调用权限

### 第三步：创建 API Key

1. 点击右上角头像 → 选择「API Keys」
2. 点击「+ Create API Key」
3. 填写 Name（随便填）和 Expiration（可选最长 12 个月）
4. 点击「Create Key」确认

> ⚠️ **重要提示**：API Key 创建成功后只显示一次！会出现 `nvapi-` 开头的字符串，务必立刻复制保存！

### 第四步：找到模型 ID

1. 访问 https://build.nvidia.com/models（100+ 可用模型）
2. 点进任意模型页面，右侧代码示例里会显示该模型的 **Model ID**
